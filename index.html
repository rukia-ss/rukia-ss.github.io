BookStore Web App

Project Overview I engineered a scalable, full-stack web application tailored for inventory management using Node.js and Express on the backend, paired with a MySQL relational database. The application serves as a comprehensive digital storefront and administrative tool, bridging the gap between user-friendly frontend design and complex backend logic. Security & Authentication Security was a primary focus of this architecture. I implemented secure user authentication by utilizing industry-standard hashing algorithms (bcrypt). This ensures that sensitive user data, specifically passwords, are never stored in plain text. Furthermore, I developed a custom Role-Based Access Control (RBAC) system using middleware. This logic differentiates between 'Admin' and 'Customer' users, automatically restricting access to sensitive administrative routes (like adding or deleting inventory) based on the user's logged-in status. Database Management The backend interacts with a normalized MySQL database to perform efficient CRUD (Create, Read, Update, Delete) operations. I wrote optimized SQL queries to handle dynamic inventory updates, ensuring real-time data consistency across the application.

Python GUI Calculator

Project Overview I developed a fully functional desktop calculator application using Python and the Tkinter library. The goal was to move beyond command-line scripts and build a user-friendly Graphical User Interface (GUI) that mimics the experience of native operating system tools. Technical Implementation I utilized Tkinter's Grid Geometry Manager to structure the layout, ensuring buttons were aligned precisely and the application resized gracefully. The core functionality relies on event-driven programming; I bound specific functions to both mouse clicks and keyboard events, allowing users to type numbers naturally or click buttons. Reliability & Testing To ensure the application was robust, I moved beyond simple arithmetic and implemented a global expression evaluation engine. I integrated comprehensive error handling (try/except blocks) to catch syntax errors and mathematical impossibilities (like dividing by zero) without crashing the app. Finally, I used Python’s unittest framework to automate testing for edge cases, ensuring 100% accuracy in calculations.
